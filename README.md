# Task Timer

A simple app to track time spent on tasks.
Uma aplicação simples para rastrear o tempo gasto em tarefas.

Developing in progress.
Em desenvolvimento.

## How to run

1. Clone the repository:

```bash
git clone https://github.com/your-username/task-timer.git
cd task-timer
```

2. Install dependencies:

```bash
npm install
```

3. Start the app:

```bash
npm run dev
```

4. Open your browser and go to `http://localhost:5173`
